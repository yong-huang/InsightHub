**版本**: v1.0
**日期**: 2026-03-29
**状态**: Draft

---

## 1. 项目背景

### 1.1 现状

目前存在两套 HTML 格式的学习文档，分别存放在不同目录中：

| 项目 | 路径 | 文件数量 | 内容领域 |
|------|------|---------|---------|
| **MindInsight** | `/projects/MindInsight` | 59 个 HTML | 学术、电影分析、财务分析、历史、文学鉴赏、哲学思辨 |
| **TechInsight** | `/projects/TechInsight` | 53 个 HTML | 编程语言、AI 框架、云平台、数据可视化、基础设施、算法、Dell 方案 |

**共计 112 个 HTML 文档**，均为自包含的独立页面（内嵌 CSS/JS，无外部依赖）。

### 1.2 问题

1. **发现困难** — 文档分散在多个子目录中，用户需要逐级浏览才能找到目标文档
2. **无法搜索** — 没有全文搜索能力，只能通过文件名推断内容
3. **缺乏组织** — 没有统一的分类、标签体系，无法跨类别浏览关联内容
4. **学习闭环缺失** — 阅读后缺乏练习和巩固环节，知识留存率低
5. **无进度追踪** — 无法记录哪些文档已读、学习进度如何

### 1.3 目标

构建一个统一的 Web 浏览平台，提供：
- 文档的统一浏览和阅读体验
- 全文搜索和分类筛选
- 标签体系管理
- AI 驱动的习题生成和评分，形成学习闭环

#### 3.5.1 习题生成 Prompt 设计

系统将文档纯文本内容（去除 HTML 标签后）发送给 AI，使用如下结构化 Prompt：

```
你是一位专业的教育出题专家。请根据以下学习文档内容，生成 {num_questions} 道练习题。

要求：
1. 题型分布：{question_types}
2. 难度分布：基础 {easy}%，中等 {medium}%，挑战 {hard}%
3. 每道题必须基于文档内容，不得超出文档范围
4. 选择题提供 4 个选项，标明正确答案
5. 判断题明确对错及解析
6. 简答题提供参考答案要点

请以 JSON 格式返回，结构如下：
{
  "questions": [
    {
      "id": 1,
      "type": "choice|truefalse|short_answer",
      "difficulty": "easy|medium|hard",
      "question": "题目内容",
      "options": ["A. ...", "B. ...", "C. ...", "D. ..."],  // 选择题必填
      "answer": "正确答案",
      "explanation": "解析说明"
    }
  ]
}

文档内容：
{document_text}
```

#### 3.5.2 评分 Prompt 设计

用户提交答案后，AI 进行评分：

```
请对学生的以下作答进行评分。

原始题目和标准答案：
{questions_json}

学生作答：
{answers_json}

评分规则：
1. 选择题：完全正确 10 分，错误 0 分
2. 判断题：完全正确 10 分，错误 0 分
3. 简答题：根据要点匹配度 0-10 分

请以 JSON 格式返回：
{
  "results": [
    {
      "question_id": 1,
      "score": 10,
      "feedback": "评语反馈"
    }
  ],
  "total_score": 85,
  "summary": "总体评价"
}
```

## 6. 数据字典

### 6.1 文档索引 (Document)

```typescript
interface Document {
  id: string;                    // 唯一标识，如 "mindinsight-academic-critical-thinking"
  title: string;                 // 文档标题（从 HTML <title> 提取）
  subtitle?: string;             // 副标题
  source: 'mindinsight' | 'techinsight';
  category: string;              // 二级分类，如 "academic", "programming"
  categoryLabel: string;         // 分类显示名，如 "学术基础"
  filePath: string;              // 相对文件路径
  tags: string[];                // 标签列表
  contentText: string;           // 纯文本内容（去标签）
  contentHtml: string;           // 原始 HTML
  readCount: number;             // 阅读次数
  lastReadAt?: string;           // 最近阅读时间 (ISO)
  isRead: boolean;               // 是否已读
  createdAt: string;             // 首次发现时间
  wordCount: number;             // 字数
  hasQuiz: boolean;              // 是否已生成过习题
}
```

### 6.2 标签 (Tag)

```typescript
interface Tag {
  id: string;
  name: string;
  color: string;                 // 十六进制颜色
  documentCount: number;         // 关联文档数
}
```

### 6.3 习题 (Quiz)

```typescript
interface Quiz {
  id: string;
  documentId: string;
  questions: Question[];
  createdAt: string;
  attempts: QuizAttempt[];
}

interface Question {
  id: number;
  type: 'choice' | 'truefalse' | 'short_answer';
  difficulty: 'easy' | 'medium' | 'hard';
  question: string;
  options?: string[];            // 选择题选项
  answer: string;
  explanation: string;
}

interface QuizAttempt {
  id: string;
  answers: Record<number, string>;
  results: QuizResult[];
  totalScore: number;
  summary: string;
  completedAt: string;
}

interface QuizResult {
  questionId: number;
  score: number;
  feedback: string;
}
```

### 6.4 搜索记录 (SearchHistory)

```typescript
interface SearchHistory {
  query: string;
  timestamp: string;
  resultCount: number;
}
```

### 6.5 用户偏好 (UserPreferences)

```typescript
interface UserPreferences {
  theme: 'light' | 'dark';
  quizDifficulty: 'mixed' | 'easy' | 'medium' | 'hard';
  quizQuestionCount: number;     // 5-10
```
